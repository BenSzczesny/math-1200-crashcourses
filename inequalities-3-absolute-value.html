Lesson 3 of 3 · absolute value

Absolute value inequalities: split it, then join it

|x| is the distance from x to 0. So |x| < 3 asks for the numbers less than 3 away from 0, and |x| > 3 asks for the numbers more than 3 away.

To solve one, split it into two inequalities, just like you split |A| = b into two equations. The new part is the word that joins them: and or or.

1 · What it means

Absolute value is distance

|x − 1| is the distance between x and 1. |x + 2| is the distance between x and −2, because x + 2 = x − (−2).

Move x and watch the distance. Then press Show to see every x that works.

Key idea

Less than means close: one piece, in between.

Greater than means far: two pieces, going outward.

2 · The method

Split, then join

Drop the bars and write two inequalities. The second one gets a negative right side and a flipped sign. Then join them with a word.

StartSplitShape
|A| < bA < b  and  A > −bone piece, between
|A| > bA > b  or  A < −btwo pieces, outside

Same for ≤ (use and) and ≥ (use or). This only works once the absolute value is alone on one side and b is positive. Sections 4 and 5 cover the other cases.

Less than|x − 1| < 3
  1. x − 1 < 3  and  x − 1 > −3Less than, so and. Second part: −3, and flip the sign.
  2. x < 4  and  x > −2Add 1 to both sides of each part.
  3. −2 < x < 4and keeps the overlap: everything between −2 and 4.
  4. (−2, 4)Check with 0: |0 − 1| = 1, and 1 < 3 is true.
Greater than|2x + 3| ≥ 7
  1. 2x + 3 ≥ 7  or  2x + 3 ≤ −7Greater than, so or. Second part: −7, and flip the sign.
  2. 2x ≥ 4  or  2x ≤ −10Subtract 3 in each part.
  3. x ≥ 2  or  x ≤ −5Divide by 2 in each part. Positive, so no flip.
  4. (−∞, −5] ∪ [2, ∞)or keeps both pieces. Check with −6: |−12 + 3| = 9, and 9 ≥ 7.
Solve|x − 2| < 5
Solve|3x| > 6
3 · Drill

and or or?

Don't solve. Get the bars alone in your head if you need to, then pick the word.

4 · Order matters

Get the bars alone first

You can only split when the absolute value is alone on one side. Anything multiplied by it or added to it has to go first, just like getting x alone.

Solve4|x − 1| + 2 < 14
  1. 4|x − 1| < 12Subtract 2 from both sides.
  2. |x − 1| < 3Divide both sides by 4. Now the bars are alone.
  3. x − 1 < 3  and  x − 1 > −3Now split. Less than, so and.
  4. −2 < x < 4,  so (−2, 4)Same as the example in section 2.
Watch out: splitting too early

Splitting 4|x − 1| + 2 < 14 straight away gives 4(x − 1) + 2 > −14 for the second part. That leads to −3 < x < 4. The right end is correct, but the left end is wrong, which is why this mistake is easy to miss.

Solve3|x + 2| − 1 ≤ 11
5 · The quick ones

A negative on the right

An absolute value is a distance, so it is never negative. Once the bars are alone, check the right side. If it is negative, you can answer straight away.

Less than a negative
|x − 5| < −2 no solution A distance can't be below −2. It can't even be below 0.
Greater than a negative
|x − 5| > −2 (−∞, ∞) Every distance is at least 0, and 0 is already bigger than −2. Every x works.

Zero on the right is a special case too:

|A| < 0no solution
|A| ≤ 0only where A = 0 (a single number)
|A| > 0every number except where A = 0
|A| ≥ 0all real numbers
Solve|x + 4| ≤ −3
6 · Putting it in order

The method, and common mistakes

  1. Get the absolute value alone on one side.
  2. Look at the right side.Negative? Stop. Less than gives no solution; greater than gives all real numbers.
  3. Split into two parts.Less than: and. Greater than: or. Second part: negative right side, flipped sign.
  4. Solve each part, like Lesson 2.
  5. Combine and write the interval, like Lesson 1.
