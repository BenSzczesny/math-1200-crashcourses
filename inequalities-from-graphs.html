Inequalities from graphs

An inequality like f(x) > 0 asks one question: where is the graph of f above the x-axis? Sketch the graph, and you can read the answer off it.

The sketches here come from the three Graphing Rational Functions courses. Do those first if you can. Sections 3 and 5 recap what you need. Sign Charts solves the same problems a second way, by testing numbers. Either one works. No calculator needed.

1 · The idea

Above the axis means positive

Every point on the graph of f is (x, f(x)). Its height is f(x). A point above the x-axis has a positive height, and a point below has a negative one. So:

Reading an inequality off a graph f(x) > 0: where the graph is above the x-axis. f(x) < 0: where the graph is below it. f(x) = 0: where it meets the axis. These are the zeros.

The answer is a set of x-values, so read it along the x-axis. Move left to right and note where the graph goes above and where it goes below.

≥ and ≤ include the zeros

≥ 0 means above or on the axis. So the zeros are in the answer, with square brackets. With > or <, the zeros are left out, with round brackets.

Try it. Pick an inequality, and the graph marks the x-values that work. Say the answer to yourself before you click.

2 · Special points

Touch points and asymptotes

Two kinds of point need care.

A touch point

Where the graph touches the axis and turns back, f is 0. So that point counts for ≥ and ≤, even when the graph is on the wrong side all around it. Then it goes in the answer on its own, in braces, like {1}. For > and < it's left out, which splits the piece around it in two.

A vertical asymptote

The graph has no point on a vertical asymptote, because f doesn't exist there. So an asymptote is never in the answer, not even with ≥ or ≤. It always gets a round bracket.

Graph 1 touches the axis at 1. Graph 2 has an asymptote at −2. Try all four inequalities on each.

3 · Sketch it

Sketch a polynomial, then read it

Usually you get a formula, not a graph. So sketch the graph first. You don't need the heights of the bumps. You only need which side of the axis the graph is on.

The sketch, from factored form
  • Zeros: set each factor to 0.
  • The ends: multiply the x term from each factor to get the leading term. Plus: above on the right. Minus: below. Even power: the left end is on the same side. Odd: the other side.
  • Walk left from the right end. At each zero, an odd power changes the sign: the graph crosses. An even power keeps it: the graph touches and turns back.
Solvex(x + 2)(x − 2) ≤ 0
  1. zeros 0, −2 and 2Set each factor to 0. Each has power 1, so the graph crosses at all three.
  2. leading term x · x · x = x3Plus and odd: above on the right, below on the left.
  3. above, then below, above, belowStart above on the right and walk left. Every power is odd, so the sign changes at 2, at 0 and at −2. It arrives below on the left, which matches the ends. Check one point: f(1) = 1 · 3 · (−1) = −3, below the axis, as drawn.
  4. (−∞, −2] ∪ [0, 2]≤ 0 means on or below the axis. The zeros are in.
Not sure of the picture?

Put one number into f and see if the result is positive or negative. That tells you which side of the axis the graph is on there. Doing that on every piece is the sign-chart method.

4 · Get it ready

Zero on one side, then factor

Reading the graph only works when the inequality compares f(x) with 0. So move everything to one side first, then factor.

Solvex3 < 6x2 − 9x
  1. x3 − 6x2 + 9x < 0Subtract 6x2 and add 9x. Now the right side is 0.
  2. x(x2 − 6x + 9) < 0Every term has an x. Take it out.
  3. x(x − 3)2 < 0x2 − 6x + 9 is a perfect square: (x − 3)(x − 3).
  4. 0 is odd, 3 is even, ends like x3x has power 1. (x − 3)2 has power 2. The leading term is x · x2 = x3: above on the right, below on the left.
  5. start above; keep at 3; change at 0Even at 3: it touches and stays above. Odd at 0: it crosses to below, which matches the left end. Check one point: f(1) = 1 · 4 = 4, above the axis.
  6. (−∞, 0)< 0 means strictly below. That's only left of 0. At 3 the graph touches the axis, so f(3) = 0, and 0 < 0 is false.
Never divide both sides by x

Divide x3 < 6x2 − 9x by x and you get (x − 3)2 < 0, which has no solution. But x = −1 works: −1 < 6 + 9. When x is negative, dividing should flip the sign, and you can't tell when it is. Move everything to one side and factor x out instead.

Fractions are the same. Never multiply both sides by the bottom. Subtract to get 0 on one side, then combine into one fraction. The Sign Charts course works one through.

Solvex3 + 2x2 < 3x
5 · Fractions

Rational inequalities: the same walk

A fraction's graph meets the axis where its top is 0. It breaks at a vertical asymptote where its bottom is 0. Both are key numbers, and one rule covers both.

The walk Right end: leading term over leading term, then simplify. Plus is above, minus is below. Odd power, top or bottom: the sign changes. Even power, top or bottom: the sign stays.

Why: an odd power like (x − 3) changes sign as x passes 3, so the fraction does too. An even power like (x + 1)2 is positive on both sides of −1, so the fraction keeps its sign. Even Keeps, Odd Changes has more on this, and practice.

Asymptotes are never in the answer. Holes aren't either, because the graph has no point there. Cancel a common factor first, and leave its x out of the answer.

Solvex + 2x − 3 ≤ 0
  1. top 0 at −2, bottom 0 at 3−2 is a zero and 3 is an asymptote. Both have power 1, so the sign changes at both.
  2. ends: xx = 1So the horizontal asymptote is y = 1, and both ends are above the axis.
  3. start above; change at 3; change at −2It's below between −2 and 3, then above left of −2. That matches the left end. Check: f(0) = 2−3, negative, as drawn.
  4. [−2, 3)On or below the axis. −2 is a zero, so it's in. 3 is the asymptote, so it's out.
Solve(x + 3)(x − 1)(x + 1)2 > 0
  1. zeros −3 and 1, asymptote −1Both zeros have power 1, so the sign changes at each. The asymptote's power is 2, even, so the sign stays there.
  2. ends: x · xx2 = 1So the horizontal asymptote is y = 1, and both ends are above the axis.
  3. start above; change at 1; keep at −1; change at −3It's below between −1 and 1, still below between −3 and −1, then above left of −3. That matches the left end. Check: f(0) = −3 and f(−2) = −3, both below.
  4. (−∞, −3) ∪ (1, ∞)Strictly above the axis, so the zeros are out.

8 · Keep this

Cheat sheet

Inequalities from a graph

  1. Read it: f(x) > 0 is above the axis, f(x) < 0 is below.
  2. Brackets: ≥ and ≤ include the zeros, even a touch point on its own. An asymptote is never in.x2(x − 4) ≥ 0:  {0} ∪ [4, ∞)
  3. Get 0 on one side, then factor. Never divide or multiply both sides by something with x in it.
  4. Start at the right end: leading term over leading term. Plus is above, minus is below.
  5. Walk left: at each zero or asymptote, an odd power changes the sign and an even power keeps it.
  6. Check: you should arrive at the left end the leading terms gave you. Or put one number in.
