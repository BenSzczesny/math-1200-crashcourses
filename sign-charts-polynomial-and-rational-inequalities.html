Inequalities · Module 18

Polynomial and rational inequalities

To solve an inequality like (x − 4)(x + 1) ≤ 0, find where the left side is 0. Those numbers cut the number line into pieces. On each piece the sign never changes, so you test one number per piece.

This uses Zeros and Multiplicity, and interval notation from Inequalities, Lesson 1. No calculator needed.

1 · The idea

Test one number per piece

First, a reminder: signs when you multiply or divide
  • Same signs give +:  (−3)(−2) = 6,  (−6) ÷ (−2) = 3.
  • Opposite signs give −:  (−3)(2) = −6,  6 ÷ (−2) = −3.
  • With more numbers, count the minus signs. An even number of them gives +, an odd number gives −:  (−1)(−2)(−3) = −6 has three, so it's −.

Dividing follows the same rule as multiplying, which matters in section 4.

A product can only change sign where one of its factors is 0. So find those numbers first. Call them the key numbers. Between two key numbers, every x gives the same sign, so one test tells you about the whole piece.

Solve(x − 4)(x + 1) ≤ 0
  1. key numbers −1 and 4Where each factor is 0. They cut the line into three pieces.
  2. test −2, 0 and 5One number from each piece: (−6)(−1) = 6,  (−4)(1) = −4,  (1)(6) = 6. The chart records just the signs. Its last column is the sign of the whole expression, from counting the minuses in the row. Only the middle piece is negative.
  3. Are −1 and 4 solutions too?Check them. At x = −1: (−5)(0) = 0. At x = 4: (0)(5) = 0. The inequality asks for ≤ 0, and 0 ≤ 0 is true. So both key numbers belong in the answer, which means square brackets.
  4. [−1, 4]Closed dots at both ends.
Do the key numbers count as solutions?

At a key number the expression is 0. With ≤ or ≥, 0 is allowed, so the key numbers are solutions: closed dot, square bracket. With < or >, 0 isn't allowed, so they aren't: open dot, round bracket.

Solve(x + 3)(x − 2) > 0
2 · Get it ready

Zero on one side, then factor

The test only works when one side is 0. So move everything to one side first, then factor.

Solvex2 + 2x ≥ 8
  1. x2 + 2x − 8 ≥ 0Subtract 8. Now the right side is 0.
  2. (x + 4)(x − 2) ≥ 0Two numbers that multiply to −8 and add to 2: 4 and −2.
  3. key numbers −4 and 2Test −5, 0 and 3: (−1)(−7) = 7,  (4)(−2) = −8,  (7)(1) = 7.
  4. (−∞, −4] ∪ [2, ∞)The two outside pieces. At −4 and 2 the product is 0, and ≥ 0 allows that, so they're included.
Never divide both sides by x

You don't know whether x is positive or negative, so you don't know whether to flip the sign. Move it to one side and factor it out instead.

3 · The sign chart

More factors? Track only the signs.

You've already seen sign charts in sections 1 and 2. What changes here is the shortcut. With three or more factors, working out each product is slow and easy to get wrong. So skip the values: write only whether each factor is + or −, then count the minuses, as in the reminder in section 1.

Solve(x + 2)(x − 1)(x − 4) < 0
  1. key numbers −2, 1 and 4Four pieces.
  2. fill in the chartEach factor is − to the left of its own key number and + to the right.
  3. (−∞, −2) ∪ (1, 4)< 0 wants the − pieces. It's strict, so the key numbers are out.
A squared factor never changes sign

(x − 1)2 is + on both sides of 1, and 0 at 1. So the product keeps its sign at that key number. It's the "touches and turns back" of Zeros and Multiplicity. So don't assume the signs alternate: an even power keeps the sign. Test every piece, or use the rule in Even Keeps, Odd Changes.

Solve(x + 2)(x − 1)2 > 0
  1. key numbers −2 and 1Where each factor is 0. The square is still a factor: (x − 1)2 = 0 at 1.
  2. fill in the chartThe (x − 1)2 column is + on every piece, because a square is never negative. So the sign only changes at −2.
  3. Is 1 a solution?At x = 1: (3)(0)2 = 0, and 0 > 0 is false. So 1 is left out, even though the pieces on both sides of it work.
  4. (−2, 1) ∪ (1, ∞)Everything right of −2, except 1.

4 · Fractions

Rational inequalities

A fraction can change sign where its top or its bottom is 0, so both give key numbers. A key number from the bottom is never in the answer: the fraction doesn't exist there.

Solvex − 1x + 2 ≥ 0
  1. key numbers 1 (top) and −2 (bottom)Where the top is 0, and where the bottom is 0.
  2. signs: +, −, +Same chart as before. Dividing follows the multiplying rule, so a minus over a minus is +.
  3. Are 1 and −2 solutions?At 1: 03 = 0, and 0 ≥ 0 is true, so 1 is a solution. At −2 the bottom is 0, so the fraction doesn't exist there. −2 can't be a solution.
  4. (−∞, −2) ∪ [1, ∞)Round bracket at −2 even though the sign is ≥.
Not 0 on one side?

Subtract to get 0 on one side, then combine into one fraction. Never multiply both sides by the bottom: it might be negative, and you wouldn't know to flip the sign.

Solve6x − 1 ≥ 2
  1. 6x − 1 − 2 ≥ 0Subtract 2 so the right side is 0.
  2. 6 − 2(x − 1)x − 1 ≥ 0To subtract, give 2 the same bottom: 2 = 2(x − 1)x − 1.
  3. 8 − 2xx − 1 ≥ 0Tidy the top: 6 − 2x + 2 = 8 − 2x.
  4. key numbers 4 (top) and 1 (bottom)8 − 2x = 0 at 4, and x − 1 = 0 at 1.
  5. (1, 4]The middle piece is +. 4 makes the fraction 0, so it's in. 1 makes the bottom 0, so it's out.

Why not multiply both sides by x − 1? You'd get 6 ≥ 2x − 2, so x ≤ 4. But x = 0 fits that, and 60 − 1 = −6, which is not ≥ 2. At x = 0, x − 1 is negative, so the sign should have flipped.

7 · Keep this

Cheat sheet

Solving with a sign chart

  1. Get 0 on one side. Never divide or multiply both sides by something with x in it.
  2. Factor, top and bottom.
  3. Key numbers: every zero of every factor, top and bottom.
  4. Test one number per piece, or chart the sign of each factor and multiply.
  5. Pick the pieces with the sign you need.
  6. Ends: ≤ or ≥ includes the top's key numbers. < or > leaves them out. The bottom's are always out.x − 1x + 2 ≥ 0:  (−∞, −2) ∪ [1, ∞)
