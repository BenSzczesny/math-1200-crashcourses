1 · Zeros

Zeros come from factors

A zero of f is an x where f(x) = 0. On the graph, it's an x-intercept.

If a product is 0, one of its factors is 0. So set each factor with an x in it equal to 0.

Read the sign carefully The factor (x − c) gives the zero x = c. So (x + 2) gives x = −2.
Find the zeros off(x) = 3(x − 4)(x + 1)(2x − 5)
  1. x − 4 = 0  gives  x = 4The sign flips: minus 4 gives plus 4.
  2. x + 1 = 0  gives  x = −1Plus 1 gives minus 1.
  3. 2x − 5 = 0  gives  x = 52Solve it: add 5, divide by 2.
  4. zeros: 4, −1, 52The 3 in front is never 0, so it gives no zero.
The zeros off(x) = (x + 6)(x − 2)
2 · Not factored yet?

Factor first

If the polynomial isn't factored, factor it. Take out a common factor first, often a power of x.

Find the zeros off(x) = x3 − 2x2 − 15x
  1. x(x2 − 2x − 15)Every term has an x. Take it out.
  2. x(x − 5)(x + 3)Two numbers that multiply to −15 and add to −2: −5 and 3.
  3. zeros: 0, 5, −3The x you took out is a factor too. It gives x = 0.

The y-intercept is a different thing: put x = 0 in. Here f(0) = 0, so it's (0, 0).

The zeros off(x) = x2 − x − 12
3 · Multiplicity

The power on the factor

The multiplicity of a zero is the power on its factor. A factor with no power written has power 1.

Zeros and multiplicities off(x) = x(x − 3)2(x + 1)3
  1. x = 0,  multiplicity 1x is x1.
  2. x = 3,  multiplicity 2From (x − 3)2.
  3. x = −1,  multiplicity 3From (x + 1)3. The multiplicities add to the degree: 1 + 2 + 3 = 6.
Inf(x) = 4x(x + 2)3(x − 1)2the zero x = −2 has multiplicity
4 · Cross or touch

Odd crosses. Even touches and turns back.

Graph behavior at a zero Odd multiplicity (1, 3, 5, …): the graph crosses the x-axis. Even multiplicity (2, 4, …): the graph touches the x-axis and turns back.

Why: (x − 1)2 is never negative, so f keeps the same sign on both sides of 1. With an odd power, the factor changes sign at the zero, and so does f.

It works backwards too. Read the graph: a crossing means odd, a bounce means even.
