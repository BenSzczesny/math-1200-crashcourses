Factoring · Part 1

Factoring is distributing, backwards

You know 3(2x + 3) = 6x + 9. Factoring goes the other way: find what the terms share, pull it out front, and put what's left in a bracket.

This page covers the common factor, difference of squares, sum and difference of cubes, and grouping. Part 2 covers quadratics (the diamond). No calculator needed.

1 · What it is

A sum goes in, a product comes out

The whole idea 6x + 9 = 3(2x + 3)

Both sides are equal for every x. Only the shape changed: the left is a sum, the right is a product. Products are what you need for cancelling fractions and for solving equations like (x − 2)(x + 5) = 0.

How to find what's shared: break each term into its factors, then look for what both piles have.

12x3
18x2

What they share is the common factor. What's left of each term goes inside the bracket.

2 · Always first

Pull out the greatest common factor (GCF)

Two parts
  • The number: the biggest number that divides every coefficient.
  • The letters: each letter that's in every term, to the lowest power you see.
Factor12x3 + 18x2
  1. 6The biggest number dividing 12 and 18 is 6.
  2. x2Both terms have x. The lowest power is x2. (x2 goes into x3, but not the other way.)
  3. 6x2 · 2x + 6x2 · 3Write each term as the GCF times what's left.
  4. 6x2(2x + 3)Pull it out front. Check by multiplying back: 12x3 + 18x2.

3 · The bracket matters

The bracket is doing real work

The factor out front multiplies everything in the bracket. Leave the bracket off and it only multiplies the first piece. Pick a value of x:

Try
Don't lose the 1
x2 + x = x(x + 1) Taking x out of x leaves 1, not nothing. Check: x · x + x · 1.
A negative flips every sign
−2x + 6 = −2(x − 3) Check: −2 · x = −2x and −2 · (−3) = 6.

4 · Pattern

Difference of squares

Know this shape a2 − b2 = (a − b)(a + b)
Factor9x2 − 16
  1. (3x)2 − 42Ask what's being squared. 9x2 = (3x)2 and 16 = 42.
  2. (3x − 4)(3x + 4)Use the pattern with a = 3x and b = 4.
It needs the minus

x2 + 9 doesn't factor (using real numbers). (x + 3)(x + 3) is x2 + 6x + 9, a different expression.

5 · Pattern

Sum and difference of cubes

Difference a3 − b3 = (a − b)(a2 + ab + b2) Sum a3 + b3 = (a + b)(a2 − ab + b2)
Remember the signs: SOAP

Same sign as the original, then Opposite sign, then Always Positive. For a3 − b3: (a − b)(a2 + ab + b2).

Factorx3 − 8
  1. x3 − 23What's being cubed? a = x and b = 2, since 23 = 8.
  2. (x − 2)(x2 + x · 2 + 22)Fill in the pattern. Signs: same (−), opposite (+), always positive (+).
  3. (x − 2)(x2 + 2x + 4)Check with x = 1: 1 − 8 = −7, and (−1)(1 + 2 + 4) = −7.

6 · Bigger factors

A bracket can be the common factor

The common factor doesn't have to be a number or a letter. It can be a whole bracket. If the same bracket multiplies both terms, pull it out front just like a 6.

The factor is a number
6x + 18 Both terms are 6 times something, so 6(x + 3).
The factor is a bracket
x(x + 2) + 3(x + 2) Both terms are (x + 2) times something, so (x + 2)(x + 3).

If the bracket is hard to see as one thing, swap it for a box:

start
both terms are it, times something
pull it out front
Three things to watch
  • The shared bracket comes out once: (x + 2)(x + 3), not (x + 2)2(x + 3).
  • A term that's just the bracket leaves a 1: w(w − 3) + (w − 3) = (w − 3)(w + 1).
  • The brackets must match exactly. (p + 3) and (p − 3) are different.

7 · Four terms

Grouping: make a shared bracket

With four terms, often nothing is shared by all four. So split them into two pairs and take the GCF out of each pair. If the same bracket shows up twice, pull it out, like in section 6.

Factor2x3 + 4x2 + 3x + 6
  1. 2x2(x + 2) + 3(x + 2)GCF of the first pair is 2x2. GCF of the second pair is 3.
  2. (x + 2)(2x2 + 3)The same bracket twice, so pull it out front.

If the third term is negative, pull out a negative. Otherwise the brackets won't match:

Factorx3 + 2x2 − 3x − 6
  1. x2(x + 2) + 3(−x − 2)Pulling out +3 gives brackets that don't match.
  2. x2(x + 2) − 3(x + 2)Pull out −3 instead. Both signs in that pair flip.
  3. (x + 2)(x2 − 3)Now the brackets match.

If adjacent terms share nothing, reorder them. Each sign moves with its term:

Factorm2 − 3n + 3m − mn
  1. m2 + 3m − mn − 3nPut terms that share something next to each other.
  2. m(m + 3) − n(m + 3)GCF of each pair. The second pair gives up −n.
  3. (m + 3)(m − n)Pull out the shared bracket.

8 · Common mistakes

Four wrong factorings

Factoring never changes the value. So put the same number into both sides: if they disagree, the factoring is wrong.
