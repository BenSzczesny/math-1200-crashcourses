Remainders, factors and zeros

Divide a polynomial P(x) by x − c, and the remainder is P(c). A remainder of 0 means x − c is a factor and c is a zero. That lets you factor a cubic once you know one zero.

Do Part 1, Polynomial Division, first. This page uses synthetic division throughout. No calculator needed.

1 · The Remainder Theorem

The remainder is P(c)

In Part 1 you wrote each answer as quotient + remainder over divisor. This page writes the same division a different way. Here is one example, start to finish.

DivideP(x) = x3 − 4x2 + 5  by  x − 3
  1. Put 3 in the box.The divisor is x − 3, so 3 goes in the box. Along the top, write the coefficients 1, −4, 0, 5. The 0 stands for the missing x term: x3 − 4x2 + 0x + 5.
  2. Bottom row: 1, −1, −3, −4Bring the 1 down. Then, column by column, multiply by 3 and add: 1 · 3 = 3 and −4 + 3 = −1. Then −1 · 3 = −3 and 0 + (−3) = −3. Then −3 · 3 = −9 and 5 + (−9) = −4.
  3. quotient x2 − x − 3,  remainder −4The quotient is one degree lower than P. P starts at x3, so 1, −1, −3 means x2 − x − 3. The last number, −4, is the remainder.

Now write that answer two ways. The second line is the first one multiplied through by x − 3. It's Part 1's check: divisor × quotient + remainder gives back the dividend.

Part 1's formx3 − 4x2 + 5x − 3 = x2 − x − 3 + −4x − 3
Times x − 3x3 − 4x2 + 5 = (x − 3)(x2 − x − 3) + (−4)

Which number is c?

c is the number that makes the divisor 0. Write the divisor as x − (a number), and that number is c. The sign flips from the one you see.

  • x − 5:  c = 5
  • x + 2 = x − (−2):  c = −2
  • x = x − 0:  c = 0

This c is the number that goes in the box. Synthetic division only works for a divisor like these.

Now put x = 3 into the example's second line:

P(3) = (3 − 3)(32 − 3 − 3) + (−4) = 0 · 3 − 4 = −4

The bracket 3 − 3 is 0, and 0 times anything is 0. So the first part vanishes, and P(3) is just the remainder. Check by putting 3 into P directly: 27 − 36 + 5 = −4.

The same happens for any division by x − c: putting in x = c makes the bracket 0.

The Remainder Theorem remainder = P(c) when P(x) is divided by x − c

So you can find P(c) by dividing or by plugging in. Dividing also gives you the quotient, and section 3 needs that.

2 · The Factor Theorem

A remainder of 0 means a factor

If the remainder is 0, the line from section 1 becomes P(x) = (x − c) · Q(x). So x − c divides in evenly: it's a factor. And by section 1, that remainder is P(c).

The Factor Theorem if P(c) = 0,  then x − c is a factor It works backwards too: if x − c is a factor, then P(c) = 0.

A zero of P is an input that makes the output 0. So c is a zero when P(c) = 0. On the graph, a zero is where the graph meets the x-axis.

Four ways to say one thing
  • P(c) = 0
  • c is a zero of P
  • dividing by x − c leaves remainder 0
  • x − c is a factor of P(x)
Is x − 2 a factor ofP(x) = x3 − 3x2 + 4?
  1. P(2) = 8 − 12 + 4 = 0,  so yesTest 2, the number that makes x − 2 zero. P(2) = 0, so by the Factor Theorem x − 2 is a factor. That already answers the question.
  2. To find the other factor, dividePut 2 in the box and 1, −3, 0, 4 along the top (0 for the missing x term). The remainder is 0, which just confirms step 1. What's new is the rest of the bottom row.
  3. P(x) = (x − 2)(x2 − x − 2)1, −1, −2 is the quotient x2 − x − 2: the other factor. Section 3 uses this to factor completely.

3 · Factor completely

One zero gives you the rest

ALEKS gives a cubic and one of its zeros. It asks for the cubic as a product of linear factors: brackets where x has power 1, like (2x + 1).

  1. Divide by x − c with synthetic division, with the zero c in the box. The remainder must be 0.
  2. Factor the quadratic in the bottom row.
  3. Write all three factors, including x − c.
−3 is a zero. Factorf(x) = 2x3 + 3x2 − 11x − 6
  1. Divide: bottom row 2, −3, −2, 0Put −3 in the box and 2, 3, −11, −6 along the top. The remainder is 0, as it must be when −3 is a zero.
  2. quotient 2x2 − 3x − 2The bottom row 2, −3, −2. It's one degree lower than the cubic, so it starts at x2.
  3. 2x2 − 4x + x − 2Factor with the diamond (Factoring, Part 3). Multiply the outside numbers: 2 · (−2) = −4. Two numbers that multiply to −4 and add to −3 are −4 and 1. Use them to split −3x into −4x + x.
  4. 2x(x − 2) + 1(x − 2) = (2x + 1)(x − 2)Group in pairs and take out what each pair has in common. Both brackets are x − 2, so it comes out as a factor.
  5. f(x) = (x + 3)(2x + 1)(x − 2)The zero −3 gives the factor x − (−3) = x + 3. Don't leave it out. All three factors are linear, so you're done.

4 · Working backwards

Build a polynomial from its zeros

Now go the other way. By the Factor Theorem, each zero c gives a factor x − c. Write one factor per zero, then multiply them together.

A zero's multiplicity is how many times it counts. A zero with multiplicity 2 has its factor twice, as a square.

Why a leading coefficient?

The zeros fix the factors, but not the number in front. (x − 1)(x + 1) and 2(x − 1)(x + 1) have the same zeros, 1 and −1. So the question names the leading coefficient, and it goes in front. If it's 1, nothing goes in front.

A quadratic with zeros −3 and 5, leading coefficient 1
  1. (x + 3)(x − 5)−3 gives x − (−3) = x + 3. 5 gives x − 5.
  2. x2 − 2x − 15Multiply out, every term by every term: x2 − 5x + 3x − 15. Then −5x + 3x = −2x.
