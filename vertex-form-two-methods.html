From standard form to vertex form

Standard form y = ax2 + bx + c hides the vertex. Vertex form y = a(x − h)2 + k shows it. There are two ways to get from one to the other. Both give the same answer.

Do Completing the Square, Part 1 first if "half it, square it" is new to you. No calculator needed.

1 · The goal

Vertex form shows the vertex

Standard form y = ax2 + bx + c the x2 term, then the x term, then the number  ·  a ≠ 0
Vertex form y = a(x − h)2 + k   has vertex   (h, k)

For example, y = 2x2 + 12x + 13 has a = 2, b = 12, c = 13. It is the walked example below, multiplied out.

The a in vertex form is the same number as the a in standard form: the number in front of x2. If a > 0 the parabola opens up, and the vertex is its lowest point. If a < 0 it opens down, and the vertex is its highest point.

Read the vertex ofy = 2(x + 3)2 − 5
  1. x + 3 = x − (−3),  so  h = −3The form has a minus. A plus in the bracket means h is negative.
  2. k = −5The number on the end, with its sign.
  3. vertex (−3, −5)a = 2 > 0, so it opens up and (−3, −5) is the lowest point.

So the job on this page is always the same: find a, h and k.

2 · Method 1, when a = 1

Complete the square: add it, then take it away

In Part 1 you added the number to both sides of an equation. A function like y = x2 − 6x + 5 has only one side to work on. So add the number and subtract it straight away. Together that adds zero, so the function doesn't change.

Write in vertex formy = x2 − 6x + 5
  1. half of −6 is −3,  (−3)2 = 9Half it, square it.
  2. y = (x2 − 6x + 9) − 9 + 5Add 9 and subtract 9.
  3. y = (x − 3)2 − 4The bracket is a perfect square. −9 + 5 = −4.
  4. vertex (3, −4)Check in the original: 32 − 6 · 3 + 5 = −4.

3 · Method 1, when a ≠ 1

Take a out of the x terms first

"Half it, square it" only works when x2 has nothing in front. So first factor a out of the two x terms. Leave the constant alone.

Write in vertex formy = 2x2 + 8x + 3
  1. y = 2(x2 + 4x) + 3Take 2 out of 2x2 and 8x only.
  2. half of 4 is 2,  22 = 4Complete the square inside the bracket.
  3. y = 2(x2 + 4x + 4 − 4) + 3Add 4 and subtract 4, inside.
  4. y = 2(x + 2)2 − 8 + 3Bring the −4 out. It was inside the 2( ), so it comes out as 2 · (−4) = −8.
  5. y = 2(x + 2)2 − 5Vertex (−2, −5).
The step people miss

The number you subtract sits inside the bracket. When it comes out, multiply it by a.

4 · Method 2

Find the vertex first, then write the form

The vertex of y = ax2 + bx + c is at x = −b2a. That number is h. Put it into the function to get k.

  1. Read a and b. Signs included.
  2. h = −b2a.
  3. k = y(h). Plug h into the original.
  4. Write y = a(x − h)2 + k. The same a.
Same function as section 3y = 2x2 + 8x + 3
  1. a = 2,  b = 8Read them off.
  2. h = −82 · 2 = −2Keep the minus in front of b.
  3. k = 2(−2)2 + 8(−2) + 3 = 8 − 16 + 3 = −5Square first: (−2)2 = 4, then times 2.
  4. y = 2(x + 2)2 − 5The same answer as section 3. The a stays 2.
Which method?

Both always work, and they give the same answer. Do one, then check with the other.
