1 · Where they come from

What a1/2 has to mean

If the product rule still works, then a1/2 · a1/2 = a1/2 + 1/2 = a1 = a. So a1/2 is the number that multiplies by itself to give a: the square root.

Unit fraction a1/n = n√a (a ≥ 0 when n is even)

2 · Signs

Roots of negative numbers

Key idea
  • Odd root of a negative number: negative. 3√−8 = −2, because (−2)3 = −8.
  • Even root of a negative number: not a real number. No real number squared gives −16.
  • A minus sign outside the root just waits: −√16 = −4.

3 · Both numbers

The bottom is the root, the top is the power

With any fraction in the exponent, use the power-of-a-power rule from Lesson 1: am/n = (a1/n)m.

Rational exponent am/n = (n√a)m = n√am (a ≥ 0)

Both orders give the same answer. Take the root first. The numbers stay small.

Root first: do this one
82/3 = (3√8)2 = 22 = 4 Small numbers, easy in your head.
Power first: more work
82/3 = 3√82 = 3√64 = 4 Now you need the cube root of 64 instead of 8.

4 · Simplifying

Pairs come out, everything else stays in

When a square root isn't a whole number, pull out any perfect squares hiding inside. There are two ways.

The algebra way
√48 = √16 · 3 = √16 · √3 = 4√3 Fast, if you spot that 16 goes into 48.
The factor tree

Break the number into primes. Circle the pairs. Each pair sends one copy out of the root. Everything else stays in. It always works, and you don't have to spot anything.

Try it. Click two identical factors to pair them. The last three are cube roots, where you need three of a kind.

5 · Combining roots

Multiplying and adding roots

Two rules

Multiply: √a · √b = √ab (for a, b ≥ 0). Then simplify.

Add: only when the number inside the root matches, like 3√5 + 2√5 = 5√5. But √2 + √3 doesn't simplify.

Multiply√6 · √3
  1. √18Multiply the numbers inside: 6 · 3 = 18.
  2. √9 · 218 = 9 · 2, and 9 is a perfect square (a pair of 3s).
  3. 3√2The pair of 3s sends one 3 out.

Adding usually needs simplifying first, so the roots match. Start with one root on its own:

First, simplify√20
  1. √4 · 520 = 2 · 2 · 5. There's a pair of 2s.
  2. 2√5The pair of 2s sends one 2 out. The 5 stays in.
Now add√45 + √20
  1. 3√5 + √2045 = 3 · 3 · 5. The pair of 3s sends one 3 out.
  2. 3√5 + 2√5Just done above: √20 = 2√5.
  3. 5√5Both are √5 now, so add the numbers in front: 3 + 2 = 5.
