Lesson 1 of 3 · writing the answer

The answer to an inequality is a set of numbers

x > 2 is true for 3, for 2.5, for 100, for 2.001. It is true for every number bigger than 2. So the answer is not one number. It is a whole set of numbers.

This page is about writing that set down. There is no solving here. That is Lesson 2.

1 · What it means

Test a number

A number is in the set if it makes the inequality true. That is the whole idea.

Drag the slider or click the line. Before you press Show, guess where the shading will be.

Key idea

The shaded part of the number line is every number that makes the inequality true.

Now put the slider exactly on 2 for x > 2, then for x ≥ 2. The number 2 is the only difference between those two sets.

2 · The endpoint

Open circle or closed circle?

The endpoint is the number in the inequality. The only question is whether it belongs in the set.

SymbolSay itEndpointCircle
<less thannot includedopen
≤less than or equal toincludedclosed
>greater thannot includedopen
≥greater than or equal toincludedclosed

Which way to shade: less than means smaller numbers, so shade left. Greater than means bigger numbers, so shade right.

Watch out

5 > x has x on the right. Flip the whole statement around so x comes first: x < 5. Same meaning, and now it is easy to read.

3 · Interval notation

Writing the set as an interval

An interval gives the left end and the right end of the shading, with a bracket at each end.

The rules
  • Write the left end first, then a comma, then the right end.
  • ( or ): that end is not included (open circle).
  • [ or ]: that end is included (closed circle).
  • ∞ and −∞ always get a round bracket. They are not numbers, so they can't be included.
Write as an intervalx ≥ −3
  1. ● at −3, shade rightDraw it first. ≥ includes −3, so the circle is closed.
  2. [−3,The left end is −3. It is included, so use a square bracket.
  3. [−3, ∞)The shading never stops going right, so the right end is ∞, with a round bracket.
Write as an intervalx < 4
  1. ○ at 4, shade left< does not include 4, so the circle is open.
  2. (−∞,The shading runs left forever, so the left end is −∞.
  3. (−∞, 4)The right end is 4. It is not included, so use a round bracket.

4 · Between

Between two numbers

−3 < x ≤ 6 says x is bigger than −3 and at most 6. In other words, x is between −3 and 6.

−3 < x ≤ 6
Each end gets its own circle and its own bracket. Open at −3 (because of <), closed at 6 (because of ≤). As an interval: (−3, 6].
Write in interval notation1 ≤ x < 5
5 · Two inequalities at once

and or or

A compound inequality is two inequalities joined by and or or. The word tells you which numbers to keep.

Key idea

and: a number has to make both true. Keep only the overlap.

or: a number only has to make one true. Keep everything shaded.

Build your own below, or start with the four examples. Shade both, then keep the overlap or keep everything.

Two of the examples catch people out:

  • Example 2: an and with no overlap gives no solution.
  • Example 3: an or can cover the whole line. The answer is all real numbers, (−∞, ∞).
The union symbol

∪ means "together with". Use it when the answer is two separate pieces with a gap between them: (−∞, −2) ∪ (3, ∞).

Write as an intervalx < −1  or  x ≥ 3
Write as an intervalx > 5  and  x < 2
Write as an intervalx ≥ 0  or  x < 4

Quick drill: does the answer need ∪?

Don't write the interval. Just picture the shading and ask: is there a gap?
