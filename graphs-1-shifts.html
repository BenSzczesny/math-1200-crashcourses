2 · The notation

Reading f(x): put x in, get y out

Instead of y = x2, we can write f(x) = x2. It's the same graph. f is the function's name, and f(x) is another way to write y.

The brackets hold the x you put in. To find f(3), replace x with 3: f(3) = 32 = 9. Put in 3, get out 9, so the point (3, 9) is on the graph.

Three ways to say one thing
  • f passes through (3, 9).
  • The point (3, 9) is on the graph of f.
  • f(3) = 9: put in x = 3, get out y = 9.

To test a point, put its x in. If you get its y, it's on the graph.

  • f(x) = x2 passes through (3, 9): f(3) = 32 = 9.
  • f(x) = |x| passes through (−4, 4): f(−4) = |−4| = 4.
  • f(x) = x2 does not pass through (2, 5): f(2) = 22 = 4, not 5.
Let f(x) = x2. Which point is on the graph of f?

Changing what goes in

f(x − 3) means: put x − 3 in where x was. That change is inside.

f(x) + 3 means: work out f(x), then add 3. That change is outside.

3 · The rule of thumb

Inside changes x, the opposite way. Outside changes y, the same way.

Every move Change the input, inside f( ): the x-coordinates change, the opposite way. Change the whole function, outside f( ): the y-coordinates change, the same way.

Outside is the easy one. y = f(x) + 3 takes every y-value of f and adds 3. It does what it says.

Inside goes the opposite way. Say f passes through (5, 2), so f(5) = 2. For y = f(x − 3) to give 2, the inside x − 3 has to be 5. So x = 8. The point moved to (8, 2): x increased by 3, so the point moved right 3, though the equation says minus 3.

4 · Outside

A number added outside moves it up or down

Up or down y = f(x) + k:   (x, y) → (x, y + k) plus is up, minus is down

Every point keeps its x and moves straight up or down, so the whole graph does.

5 · Inside

A number added inside moves it sideways, opposite the sign

Left or right y = f(x − h):   (x, y) → (x + h, y) x − 2 is right 2  ·  x + 2 is left 2

Every point keeps its y and slides sideways, the opposite way to the sign.

A quick check

What x makes the inside 0? That is where the parent's vertex, corner or starting point goes.

6 · Backwards

Writing the equation from the move

Up and down go outside, as they are. Sideways goes inside, with the opposite sign.
