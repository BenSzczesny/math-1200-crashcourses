1 · What it says

Each line is a rule and a condition

Some things change their rule partway. A parking lot might charge a flat $5 for up to 2 hours, and $3 an hour after that. One price, two rules, and the time decides which rule you're on. A piecewise function works the same way:

The part after "if" is a question about x. For a given x, ask each question in turn. The rule whose answer is "yes" is the one you use.

Read it as: if x < 1, use x + 3. If x ≥ 1, use x2. Every x passes exactly one condition. Pick an x:
